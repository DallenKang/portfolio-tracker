## 给 Codex 的固定要求（每次都适用）

1. **先读 `../AGENTS.md`** —— 里面有绝对不能碰的东西和踩过的坑。
2. **用中文回覆**（马来西亚式，财经词可夹英文）。使用者不是程序员，讲效果不讲实现细节。
3. **改动前先说明影响**，特别是碰到费用/损益计算的时候。
4. **不要在未经同意的情况下 `git push`。**
5. **宣称「完成」之前要有证据** —— 指令输出、实际验证结果。只查了一部分就说清楚查了哪部分。
6. **改动 HTML 後，回覆结尾附可点击连结**（本机预览 http://localhost:8745/portfolio-tracker.html，给之前先确认 server 在跑）。
7. 记得 `worker.js` 和 `apps-script.gs` **改本机档案不会自动上线**，要提醒使用者手动部署（步骤在 AGENTS.md）。
